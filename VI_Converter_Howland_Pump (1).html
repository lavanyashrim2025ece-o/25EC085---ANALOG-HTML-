Definition

A voltage-to-current (V–I) converter is a circuit that produces an output current IL proportional to an input voltage Vin and, ideally, independent of the load connected to it: IL = Gm·Vin, where Gm is a transconductance in siemens (A/V). The circuit in your simulation is the Howland current pump, which drives a load that has one terminal grounded.

Fundamental operating principle

The op-amp uses both negative feedback (R3–R4 to the inverting input) and positive feedback (R2 to the non-inverting input). When the resistor ratios are matched, the op-amp automatically adjusts its output so that whatever the load voltage becomes, the load still receives exactly Vin/R1. In other words, the circuit behaves as a source with (ideally) infinite output resistance.

Why it matters

  • Sensors, actuators and transmission lines are often easier to drive with a current than with a voltage (no voltage drop due to wire resistance).
  • Industrial 4–20 mA loops, LED/laser drivers, electrode stimulators, bio-impedance front ends and ATE “force-current” channels all use V–I conversion.
  • It is a very common GATE and interview topic because it tests feedback, virtual short, KCL and resistor-matching ideas at once.

Prerequisite concepts

  • Ideal op-amp: infinite gain, infinite input resistance, zero output resistance, V+ = V− when negative feedback dominates (virtual short).
  • Kirchhoff’s Current Law (KCL), voltage dividers, Ohm’s law, Norton/Thevenin equivalents.
  • Positive vs. negative feedback and stability.

3. Working Principle and Detailed Explanation

Step-by-step operation

  1. Input. V1 pushes a current through R1 towards node 2, which is the non-inverting input and also the top of the load R5.
  2. Negative feedback. R3 and R4 form a divider from the output to the inverting input: V− = Vo·R4/(R3+R4). With R3 = R4, V− = Vo/2.
  3. Virtual short. The op-amp adjusts Vo until V+ = V−. Since V+ is the load voltage VL, the output must be Vo = VL(1 + R3/R4) = 2VL.
  4. Positive feedback adds the missing current. R2 carries (Vo − VL)/R2 = VL/R2 into node 2. R1 carries (Vin − VL)/R1. Their sum is the load current.
  5. Result. With R1 = R2, the VL terms cancel in the sum and IL = Vin/R1, whatever RL is (within compliance).

Input-to-output signal flow

Vin → R1 → node 2 → (+) input of U1 → output node 4 → R2 back to node 2 and R3 back to node 3. The load current always flows from node 2 to ground. A positive Vin gives positive IL into R5 and a positive Vo.

DC and AC behaviour

  • DC: IL = Vin/R1 = 2 V/1 kΩ = 2 mA, VL = 2 V, Vo = 4 V (ideal theory; see §4 for the predicted node voltages).
  • AC (low frequency): a sine Vin gives an in-phase sine IL with the same shape and Gm = 1/R1; Vo is also in phase and twice the load-voltage amplitude.
  • AC (high frequency): finite gain–bandwidth product makes the real output resistance fall with frequency, the matching degrades, and capacitive loads can threaten stability.

Operating modes / conditions

  • Regulating (linear) region: |Vo| < Vsat. Current is load-independent.
  • Saturated region: Vo hits the supply limit; the op-amp can no longer enforce the virtual short and IL falls below Vin/R1 (see the lab below).
  • Unstable region (mismatch): if the positive feedback exceeds the negative feedback for some loads, the circuit latches or oscillates.

Assumptions and approximations

  • Ideal op-amp: no input bias current, infinite gain, V+ = V−.
  • Resistors perfectly matched (R2/R1 = R3/R4).
  • |Vo| below saturation; output current below the op-amp’s current limit.

Advantages, limitations, design considerations

Advantages
  • Load can have one terminal grounded.
  • Bidirectional current (positive and negative IL).
  • Very high Ro with good matching.
  • Gain set by a single resistor R1.
Limitations
  • Needs four well-matched resistors.
  • Compliance is only about half the swing when R3 = R4 (Vo = 2VL).
  • Op-amp must supply more current than the load current (4 mA vs 2 mA in your circuit).
  • Stability depends on matching and load.

Design tips: use 0.1 % or better thin-film resistor arrays (they track with temperature), keep R values large enough that op-amp output current is modest but small enough that noise and bias-current errors stay low, choose a rail-to-rail or high-voltage op-amp when more compliance is needed, and verify stability with the real load capacitance.

Common student misconceptions

MisconceptionReality
“R2 gives positive feedback, so the circuit must be unstable.”Net feedback is negative as long as the positive-feedback fraction is smaller than the negative one. With equal resistors, β+ = (R1∥RL)/(R2+R1∥RL) < ½ = β−, so it is stable.
“The op-amp output voltage equals the load voltage.”Vo = VL(1+R3/R4) = 2VL here.
“V1 supplies the load current.”In your circuit VL = 2 V = Vin, so the current through R1 is zero; the op-amp supplies all 2 mA through R2.
“Current is constant for any load.”Only within the compliance limit. RL,max = Vsat/(2 IL) for R3 = R4.
“Any four equal-ish resistors will do.”1 % mismatch of one resistor gives only Ro ≈ 100·R (e.g. ≈1 MΩ for 10 kΩ resistors).

5.2 Derivation of the load current (ideal op-amp, any resistor values)

Step 1 – Inverting-input voltage (divider R3, R4):

V− = Vo · R4/(R3 + R4)

Step 2 – Virtual short (V+ = VL = V−):

Vo = VL(1 + R3/R4)

Step 3 – KCL at node 2 (op-amp input current = 0):

(Vin − VL)/R1 + (Vo − VL)/R2 = IL = VL/RL

Step 4 – Substitute Vo: (Vo − VL)/R2 = VL·R3/(R2R4), hence

IL = Vin/R1 + VL · [ R3/(R2R4) − 1/R1 ]   (general result)

Step 5 – Matching condition. If R3/R4 = R2/R1 (equivalently R1R3 = R2R4), the bracket is zero:

IL = Vin/R1    Gm = 1/R1   (independent of RL)

Physical meaning: the bracket is the conductance of the pump’s output port. Zero conductance means infinite output resistance – an ideal current source.

5.3 Output resistance and mismatch

Define g = R3/(R2R4) − 1/R1. Then IL = Vin/R1 + g·VL, so the pump is a Norton source with

Ro = −1/g = 1 / [ 1/R1 − R3/(R2R4) ]
  • g < 0 → Ro positive and finite (ordinary, stable behaviour).
  • g > 0 → Ro negative: positive feedback is too strong; instability is possible for RL ≥ |Ro|.
  • Exact load current with mismatch: IL = (Vin/R1)/(1 − g RL) (valid while 1 − gRL > 0 and the op-amp is not saturated).
  • Special case R1 = R2 = R3 = R and R4 = R(1+ε): Ro = R(1+ε)/ε ≈ R/ε. A 1 % error gives Ro ≈ 100R.

5.4 Compliance (maximum load)

|Vo| = |IL|·RL·(1 + R3/R4) ≤ Vsat  ⟹  RL,max = Vsat / [ |IL|(1 + R3/R4) ]

For R3 = R4: RL,max = Vsat/(2|IL|). Vsat is typically 1–2 V below the supply for general-purpose op-amps; the value depends on the part and load, so check the data sheet. When saturated, VL = (Vin/R1 + Vo/R2) / (1/R1 + 1/R2 + 1/RL) with Vo = ±Vsat.

5.5 Power and efficiency

PL = IL2RL,    Io = (Vo − VL)/R2 + Vo/(R3+R4),    Pout,opamp = VoIo

Your circuit (R = 1 kΩ, Vin = 2 V): PL = 4 mW; Io = 2 mA + 2 mA = 4 mA; Pout,opamp = 4 V × 4 mA = 16 mW. Dissipation: R2, R3, R4 = 4 mW each, R1 = 0, load = 4 mW (total 16 mW). Output-stage efficiency ≈ 25 % (ideal).

5.6 Input resistance and source current

Iin = (Vin − VL)/R1 = (Vin/R1)(1 − RL/R1)

When RL = R1 the source supplies no current (your schematic). When RL > R1 the source current reverses sign. The source should therefore have low output resistance, since any series resistance adds to R1 and changes Gm.

5.7 Offset error

For equal resistors, an op-amp input offset voltage Vos (V+ − V− = Vos) produces IL = (Vin − 2Vos)/R, so ΔIL = −2Vos/R. For R = 1 kΩ and Vos = 1 mV the error is 2 µA.

5.8 Stability condition (qualitative)

Negative feedback fraction β− = R4/(R3+R4); positive feedback fraction at node 2 β+ = (R1∥RL)/(R2+R1∥RL). The circuit is stable (at DC) when β+ < β−. For equal resistors β+ < ½ = β− for all RL.

5.9 Decibel note

Gain in dB is not central for a V–I converter, but the equivalent voltage gain of the output stage is Vo/VL = 1 + R3/R4 = 2 → 20 log102 ≈ 6.02 dB. Mismatch error can be expressed as RL/Ro (fractional current error).

6. Solved Numerical Problems

Problem 1 (Easy) – Basic Howland pump

Given: Vin = 5 V; R1 = R2 = R3 = R4 = 10 kΩ; RL = 2 kΩ; ±15 V supplies. Find: IL, VL, Vo.

Formula: IL = Vin/R1; VL = ILRL; Vo = VL(1 + R3/R4).

IL = 5 V / 10 kΩ = 0.5 mA; VL = 0.5 mA × 2 kΩ = 1 V; Vo = 1 V × 2 = 2 V.

Interpretation: Vo is well inside ±15 V, so the pump regulates. The resistors are matched (R2/R1 = R3/R4 = 1).

Problem 2 (Moderate) – Design with compliance

Given: need IL = 4 mA from Vin = 2 V; choose R3 = R4 = 10 kΩ; Vsat ≈ 13 V (assumed). Find: R1, R2 and the largest load.

Formulas: R1 = Vin/IL; R2 = R1·(R3/R4); RL,max = Vsat/(IL(1+R3/R4)).

R1 = 2 V / 4 mA = 500 Ω. R3/R4 = 1 ⟹ R2 = 500 Ω. RL,max = 13 V / (4 mA × 2) = 1.625 kΩ.

Interpretation: a 4 mA pump with this ratio can drive only up to about 1.6 kΩ. For more compliance, use an op-amp with higher supply/output swing. Also check the op-amp output current: Io = (Vo − VL)/R2 + Vo/(R3+R4).

Check at the limit: VL = 4 mA × 1.625 kΩ = 6.5 V; Vo = 13 V; Io = (13 − 6.5)/0.5 kΩ + 13/20 kΩ = 13 mA + 0.65 mA ≈ 13.7 mA. This is above the output-current capability of many general-purpose op-amps, so in practice the output-current limit, not only Vsat, can set the maximum load. Using a larger R2 would need a correspondingly larger R1 (matching), which lowers Gm.

Problem 3 (GATE-style, Difficult) – Mismatch and output resistance

Given: R1 = R2 = R3 = 10 kΩ, R4 = 10.1 kΩ (1 % high). Ideal op-amp, Vin = 1 V. Find: Ro, and the change in IL when RL changes from 100 Ω to 2 kΩ.

Formula: Ro = 1/[1/R1 − R3/(R2R4)].

1/R1 = 100 µS. R3/(R2R4) = 1/R4 = 1/10.1 kΩ = 99.0099 µS. Difference = 0.9901 µS. So Ro = 1.01 MΩ.

IL = (Vin/R1)/(1 − gRL) with g = −0.9901 µS: RL = 100 Ω → 100 µA/1.0000990 = 99.990 µA; RL = 2 kΩ → 100 µA/1.001980 = 99.802 µA. ΔIL ≈ −0.19 µA (≈ 0.19 %).

Interpretation: a 1 % mismatch makes Ro about 100·R. The load current is still within 0.2 % for this range but is no longer perfectly load-independent. Shortcut: if R1 = R2 = R3 = R and R4 = R(1+ε), then Ro ≈ R/ε (sign of ε decides stable vs. negative Ro).

Problem 4 (Moderate) – Your Multisim circuit, node by node

Given: Vin = 2 V; R1…R5 = 1 kΩ. Find: all node voltages and branch currents.

IL = 2 V/1 kΩ = 2 mA → V2 = VL = 2 V. V3 = V2 = 2 V (virtual short). V4 = V3(1 + 1k/1k) = 4 V. IR1 = (2 − 2)/1k = 0. IR2 = (4 − 2)/1k = 2 mA. IR3 = (4 − 2)/1k = 2 mA = IR4 (2 V/1 kΩ). KCL at node 2: 0 + 2 mA = IL ✓. Op-amp output current = 2 + 2 = 4 mA.

Interpretation: these are the values to compare against your Multisim operating point.

Industry perspective

In real projects the Howland pump is rarely used “as drawn” at high current. Designers usually (1) choose matched resistor arrays or laser-trimmed networks, (2) pick an op-amp with enough output-voltage swing for 2×VL and enough output current for the extra branch current, (3) add small compensation capacitors and verify stability with the actual cable and load capacitance, (4) budget errors from resistor tolerance, op-amp offset, bias current and temperature drift, and (5) validate in the lab with a precision DMM or source-measure unit, sweeping the load while watching current. For hardware validation and ATE roles, the same concepts appear as programmable current sources with compliance limits and clamps.

Design, implementation and test challenges

  • Resistor matching and temperature tracking set Ro and linearity.
  • Compliance is limited to about Vsat/2 on the load when R3 = R4; rail-to-rail and higher-voltage op-amps extend this.
  • Capacitive loads and cables can cause oscillation; test with the actual load.
  • Measuring Ro in the lab requires a precision meter and several load values (see Interview Q6).
